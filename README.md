## 🚀 Highlighted Projects

### ⚡ [PS Fitness](https://github.com/Parshav2304/ps_fitness)
*Your Elite AI-Powered Health & Wellness Coach*
- **Description**: An end-to-end fitness platform featuring context-aware coaching, in-memory product scanning caches, and visual meal analysis.
- **Tech Stack**: FastAPI, React.js, MongoDB, Google Gemini 2.5 Flash, Chart.js.
- **ML Integration**: Integrates a custom-trained **XGBoost Classifier** (with 5-fold cross-validation) to predict personalized fitness plans.

### 🦅 [GarudaRush](https://github.com/Parshav2304/GarudaRush)
*ML-Enhanced DDoS Attack Detection & Monitoring System*
- **Description**: A comprehensive network traffic analysis tool capturing real-time flows, monitoring agent status, and alerting on active threats.
- **Tech Stack**: Flask, React, MongoDB, PyShark, Scikit-learn.
- **ML Integration**: Real-time packet parsing and ML classification for active DDoS intrusion detection.

### 🛡️ [PhishScan](https://github.com/Parshav2304/Phishscan-Detection)
*Chrome Extension Threat Intelligence & Redirection Resolver*
- **Description**: A Manifest V3 Google Chrome extension designed to scan, parse, and highlight phishing or malicious URLs in real time.
- **Tech Stack**: JavaScript, HTML5/CSS3, Manifest V3.
- **Threat Integration**: Queries VirusTotal API and Google Safe Browsing, with a fallback local OpenPhish threat intelligence feed. Features a custom parser for incoming emails on Gmail.

### 🏥 [Hospital Recommender System](https://github.com/Parshav2304/Hospital-Recommender-System)
*Hybrid Text Mining & Coordinates Geodesic Recommendation Engine*
- **Description**: A Jupyter Notebook project proposing optimal healthcare facilities based on a user's location and specific symptom requirements.
- **Tech Stack**: Pandas, NumPy, Scikit-learn, Geopy, Matplotlib.
- **Algorithm**: Implements **TF-IDF Vectorization** and **Cosine Similarity** on department metadata, combined with **Geodesic distance filtering** from geo-coordinates.
